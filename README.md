# Iswarya Ramachandran — Portfolio

A static, responsive portfolio built for GitHub Pages.

## Preview locally

Open `index.html` in a browser, or run a small local server from this folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish on GitHub Pages

Create a repository named `iswaryaramachandran-hub.github.io`, then push the contents of this `portfolio` folder to the repository's `main` branch. In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.

The published site will be available at `https://iswaryaramachandran-hub.github.io`.
